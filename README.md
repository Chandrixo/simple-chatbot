# simple-chatbot
Developed a basic chatbot using HTML, CSS, and JavaScript that simulates a simple conversation with users. The chatbot responds to predefined inputs and can answer basic queries like greetings, time, and help messages.
🔹 Features:

Static UI with a chat window and input box

Rule-based response system using JavaScript if-else conditions

Clean, responsive design using CSS
🔹 Technologies Used: HTML, CSS, JavaScript
